# Link icon attribution

Linky bundles SVG icons from React Icons **5.7.0**. No icon is fetched at runtime.

- **Font Awesome 6**, by Fonticons, Inc. ([project](https://fontawesome.com/), [React Icons collection](https://react-icons.github.io/react-icons/icons/fa6/)), supplies all platform marks except Kick and Substack, plus the generic chain-link icon. These SVGs are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The packaged SVG paths are unchanged; Linky controls size and inherited color.
- **Simple Icons** ([project](https://simpleicons.org/), [React Icons collection](https://react-icons.github.io/react-icons/icons/si/)) supplies `SiKick` and `SiSubstack`, licensed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The packaged SVG paths are unchanged.
- The **React Icons** wrapper code is copyright 2018 kamijin_fanta and licensed under [MIT](https://github.com/react-icons/react-icons/blob/master/LICENSE). Its full license notice ships in `node_modules/react-icons/LICENSE` and the pinned npm package.

Brand marks belong to their respective owners. Their use identifies a link label and does not imply endorsement. The registry in `src/features/profiles/link-platforms.tsx` records each selected packaged export.
