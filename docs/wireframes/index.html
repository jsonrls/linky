Dashboard, editor, and public profile. Desktop and mobile structure for one owner managing several profiles.

01 / Dashboard

The next decision is which profile to work on. A list keeps names, URLs, and publication status easy to compare.

01 Public handle remains visible beside the owner label to distinguish profiles with similar names.

02 Edit is the primary action. View live and Share exist only for published profiles.

03 Search and filters stay above the list. Returning from the editor preserves them.

04 On mobile, actions wrap below each identity. No horizontal table scrolling or hidden navigation is needed.

02 / Editor

Editing changes a private draft. Saving and publishing have separate status messages and separate consequences.

01 The profile switcher always shows name and handle. A failed save is resolved before switching away.

02 Content, Appearance, and Settings edit the same draft. View live opens the currently published snapshot.

03 Preview is a separate full-width view on mobile, with Back to edit and profile identity at the top.

04 Move up/down supplements dragging. A moved block keeps focus and its position is announced in the eventual product.

05 Publishing controls are in document flow in this wireframe; implementation may make them sticky only with reserved space.

03 / Public profile

A focused reading column helps visitors identify the owner, choose a destination, or send an inquiry. No account is required.

01 Only the published snapshot appears here. Owner labels, account emails, draft blocks, and editor controls never appear.

02 Links use descriptive labels and fill the reading column. Images reserve height and include owner-supplied alt text.

03 The Pro example includes a contact block. A Free profile has no inquiry form. Show platform branding when required by the confirmed entitlement policy.

04 The form explains who receives the message. Its success state confirms receipt, not that the owner has read it.

05 On wider screens, extra width becomes outer margins. The mobile reading order remains unchanged.
