Images were prompted as 390 × 844 mobile compositions; generated raster dimensions may differ. Copy, contrast, responsive behavior, keyboard interaction, and brand icons require implementation review. Image generation may introduce minor copy artifacts (notably the name in concept 17).

## Prompt direction set

Shared brief: production-quality public bio page, sans-serif only, distinct composition and hierarchy, readable body text and generous touch targets, no device chrome or invented social metrics. The three user-provided references were attached as moodboard inspiration to every generation. Individual directions follow the descriptions above. Full exact generation prompts are recorded in this chat.

## Visual review notes

All 20 outputs were inspected in the chat. They vary opening emphasis, portrait placement, link grouping and imagery. These are concept targets, not accessibility-certified interfaces. Before implementation, correct generated copy and check light text on orange/seafoam in concept 20; reduce overly narrow or small text in concept 5.
